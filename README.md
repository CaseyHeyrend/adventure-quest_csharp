# Overview

I am creating a mini RPG in C# called Adventure Quest. The purpose of this project is to practice using C# to create an interactive program with different classes, methods, properties, and game mechanics.

Adventure Quest is a text-based RPG where the player can explore different locations, fight enemies, use health and mana potions, and make choices throughout the game. The player has health, mana, attack, and defense stats. The game also includes different enemies and locations that the player can explore. The player must progress through the game and eventually reach the final boss. The game also gives the player the option to quit.

I wrote this software to learn more about C# and how to use the language to build a program with multiple classes that work together. I wanted to practice using things such as classes, inheritance, properties, methods, conditionals, loops, and random numbers. This project also helped me learn how to organize a larger program into multiple files instead of putting everything into one file.
